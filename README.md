# java-pairmatching

# 📌 요구사항 요약

우테코 미션을 함께할 페어 관리 프로그램

- 동일 레벨에서는 같은 페어 존재 불가능 (중복이라면 재매칭 시도 최대 3번)
  <br/>

# 📝 구현할 기능 목록

### 과정, 레벨, 미션 정보에 맞게 생성하는 기능

- [x] `백엔드`, `프론트엔드` 과정을 `enum`으로 등록한다.
- [x] 레벨 1부터 5까지 `enum`으로 등록한다.
- [x] 아직 페어 목록이 비어있는 미션들을 생성한다.

### 크루 정보를 md 파일에서 읽어오는 기능

- [x] 각 과정에 맞게 크루를 생성한다.

### 기능 목록을 출력하고 입력받는 기능

- [x] 기능 목록을 출력한다.
- [x] 이용할 기능 선택(`1-4` or `Q`)을 입력받는다.
    - [x] 입력이 올바른지 검증한다.

### 페어 매칭 기능

- [x] 과정과 미션 목록을 출력한다.
- [x] 페어를 매칭할 과정과 레벨, 미션을 입력받는다.
    - [x] `, ` 구분자 형식이 맞는지 검증한다.
    - [x] 존재하는 과정, 레벨, 미션인지 검증한다.
- [x] 이미 매칭이 존재한다면 재매칭을 시도할 지 출력하고 입력받는다.
    - [x] `네`나 `아니오`인지 검증한다.
- [x] `missionutils.Randoms`의 `shuffle()`로 크루 목록을 섞는다.
    - [x] 섞인 목록에서 앞에서부터 2명씩 페어를 맺는다.
    - [x] 선택한 과정의 같은 레벨 미션 중 동일한 페어가 존재하는지 확인한다.
        - [x] 동일한 페어가 존재한다면 다시 처음부터 크루 목록을 섞는다.
        - [x] 3회까지 재시도하고, 매칭이 되지 않는다면 에러 메시지를 출력한다.
    - [x] 크루 인원이 홀수라면, 마지막 페어는 3명으로 이뤄진다.

### 페어 조회 기능

- [x] 과정과 미션 목록을 출력한다.
- [x] 페어를 매칭할 과정과 레벨, 미션을 입력받는다.
    - [x] `, ` 구분자 형식이 맞는지 검증한다.
    - [x] 존재하는 과정, 레벨, 미션인지 검증한다.
- [x] 매칭 이력이 없다면 없다고 출력한다.
- [x] 선택한 과정과 레벨의 미션에서 페어 목록을 출력한다.
    - [x] 페어 출력 시, 크루 사이에 ` : `로 구분해 출력한다.

### 페어 초기화 기능

- [x] 모든 과정의 모든 레벨의 미션에서 페어 목록을 초기화한다.
- [x] 초기화되었음을 출력한다.

### 종료 기능

- [x] 사용자가 `Q` 입력 시, 반복하지 않고 종료한다.
